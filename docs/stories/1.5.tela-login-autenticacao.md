## Story

**As a** usuário do sistema,
**I want** uma tela de login com autenticação JWT e controle de acesso baseado em papéis,
**so that** eu possa acessar o sistema de forma segura com permissões adequadas ao meu papel.

---

## Acceptance Criteria

1. Tela de login com formulário (email + senha)
2. Validação de formulário em tempo real (email válido, senha mín 6 caracteres)
3. Autenticação JWT implementada no backend
4. Token armazenado em cookie HTTP-only (segurança)
5. Middleware de autenticação protege rotas do dashboard
6. RBAC implementado com 3 papéis: ADMIN, GESTOR_ESTADUAL, CONSELHEIRO_MUNICIPAL
7. Redirecionamento para `/login` se não autenticado
8. Redirecionamento para `/` após login bem-sucedido
9. Botão de logout limpa sessão e redireciona para login
10. Mensagens de erro amigáveis (credenciais inválidas, sessão expirada)
11. Loading state durante autenticação
12. Tela de login responsiva e estilizada com o design system

## Dev Notes

### Contexto do Projeto

Sistema de autenticação e autorização que protege o acesso às funcionalidades do sistema. Implementa JWT com cookies HTTP-only para máxima segurança.

### Fluxo de Autenticação

```
1. Usuário acessa rota protegida
2. Middleware verifica cookie JWT
3. Se não autenticado → redirect /login
4. Usuário preenche formulário
5. POST /api/auth/login
6. Backend valida e retorna JWT em cookie
7. Frontend redireciona para /
8. Middleware permite acesso
```

### Papéis e Permissões

| Papél | Acessa | Não Acessa |
|-------|--------|-----------|
| ADMIN | Tudo | — |
| GESTOR_ESTADUAL | Dashboard, Mapa, Ranking, Alertas, Gestão | Portal Conselho |
| CONSELHEIRO_MUNICIPAL | Portal do Conselho | Dashboard, Mapa, Ranking |

### JWT Payload

```json
{
  "sub": "user-uuid",
  "email": "user@example.com",
  "role": "GESTOR_ESTADUAL",
  "municipioId": 4314902,
  "iat": 1710500000,
  "exp": 1710503600
}
```
