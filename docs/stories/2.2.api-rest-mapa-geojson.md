## Story

**As a** desenvolvedor frontend,
**I want** uma API REST para GeoJSON dos 497 municípios com status e score,
**so that** o mapa choropleth possa renderizar cada município com sua cor correspondente ao status.

---

## Acceptance Criteria

1. Endpoint `GET /api/mapa/geojson` implementado
2. Retorna FeatureCollection GeoJSON com 497 features
3. Cada Feature contém:
   - `geometry`: polígono do município (coordenadas)
   - `properties`: codigo_ibge, nome, status, indice_antifome, populacao
4. Coordenadas dos polígonos vindas de arquivo GeoJSON do IBGE
5. Status e score vindos do banco de dados (inner join)
6. Response < 500ms (arquivo grande)
7. Cache agressivo implementado (TTL 1 hora)
8. Autenticação JWT obrigatória
9. Endpoint alternativo `GET /api/mapa/geojson/:municipioId` para detalhe único
10. Documentação Swagger completa

## Dev Notes

### Contexto do Projeto

API que alimenta o mapa choropleth do dashboard. Combina geometria do IBGE com dados do banco para renderização colorida por status.

### Response Schema

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Polygon",
        "coordinates": [[[lng, lat], ...]]
      },
      "properties": {
        "codigo_ibge": "4314902",
        "nome": "Porto Alegre",
        "status": "ATIVO",
        "indice_antifome": 8.5,
        "populacao": 1488000
      }
    },
    ...
  ]
}
```

### Fonte do GeoJSON

Arquivo estático: `backend/public/data/rs-municipios-geojson.json`
- Formato: FeatureCollection
- CRS: WGS84 (EPSG:4326)
- Cada feature: polígono com código IBGE

### Cores do Mapa (Choropleth)

| Status | Cor | Hex |
|--------|-----|-----|
| ATIVO | Verde | `#2E7D32` |
| ATRASADO | Âmbar | `#FF8F00` |
| INATIVO | Vermelho | `#D32F2F` |
