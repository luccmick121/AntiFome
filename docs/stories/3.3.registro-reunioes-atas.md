## Story

**As a** conselheiro,
**I want** registrar reuniões do conselho e enviar atas em PDF,
**so that** o histórico de reuniões fique documentado e o índice antifome seja atualizado automaticamente.

---

## Acceptance Criteria

1. Página `/conselho/reunioes` com lista de reuniões
2. Formulário de nova reunião:
   - Data da reunião
   - Tipo: ORDINARIA ou EXTRAORDINARIA
   - Pauta (texto longo)
   - Participantes (múltiplos membros)
3. Upload de ata em PDF (máx 10MB)
4. Lista de reuniões com ordenação por data (mais recente primeiro)
5. Cada reunião mostra: data, tipo, pauta resumida, se tem ata
6. Download de ata disponível
7. Reunião registrada atualiza automaticamente:
   - Índice Antifome do município
   - Progresso para próximo selo
8. API backend com CRUD e upload
9. Validações: data não futura, pelo menos 1 participante

## Dev Notes

### Contexto do Projeto

Registro de reuniões é a principal atividade do conselho. Cada reunião registrada contribui para o índice antifome e progresso de selos.

### DTO de Reunião

```typescript
interface CreateReuniaoDto {
  data: string;         // ISO date, not future
  tipo: 'ORDINARIA' | 'EXTRAORDINARIA';
  pauta: string;        // min 10 chars
  participantes: number[];  // array de membro IDs
  ata?: File;           // PDF, max 10MB
}
```

### Recálculo do Índice Antifome

```
Após registrar reunião:
1. Contar reuniões do último ano
2. Contar relatórios do último ano
3. Recalcular: ((reunioes/12) × 0.4 + (relatorios/5) × 0.6) × 10
4. Atualizar Municipio.indiceAntifome
5. Verificar se atingiu requisitos de novo selo
```

### Armazenamento de Atas

```
uploads/
└── atas/
    └── {conselhoId}/
        ├── reuniao-{id}-ata.pdf
        └── reuniao-{id}-ata.pdf
```
