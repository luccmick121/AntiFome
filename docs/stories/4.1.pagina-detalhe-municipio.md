## Story

**As a** gestor estadual,
**I want** uma página de detalhe do município com todas as informações consolidadas,
**so that** eu possa ter visão completa de um município específico incluindo conselho, membros, recursos, histórico e selos.

---

## Acceptance Criteria

1. Página `/municipios/{id}` dinâmica por município
2. Header com: nome, código IBGE, status, índice antifome
3. Seções da página:
   - **Conselho**: status, data criação, presidente atual
   - **Membros**: lista de membros atuais
   - **Recursos SAN**: recursos financeiros alocados
   - **Histórico**: timeline de reuniões e eventos
   - **Selos**: selos conquistados e progresso atual
4. Gráfico de evolução do índice antifome (últimos 12 meses)
5. Links para ações: "Ver no mapa", "Ver relatórios"
6. Dados agregados da API
7. 404 elegante se município não existe
8. Loading skeleton durante carregamento

## Dev Notes

### Contexto do Projeto

Página central de consulta do gestor estadual. Consolida todas as informações de um município em uma única visão.

### Estrutura da Página

```
┌─────────────────────────────────────────────┐
│ HEADER: Porto Alegre (4314902) | ATIVO | 8.5│
├─────────────┬───────────────────────────────┤
│             │ Índice Antifome (gráfico)     │
│ Conselho    ├───────────────────────────────┤
│ Card        │ Selos Grid                    │
│             │                               │
├─────────────┼───────────────────────────────┤
│ Membros     │ Histórico de Reuniões         │
│ List        │ (timeline)                    │
│             │                               │
├─────────────┴───────────────────────────────┤
│ Recursos SAN                                │
└─────────────────────────────────────────────┘
```
