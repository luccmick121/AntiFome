## Story

**As a** desenvolvedor,
**I want** implementar o schema Prisma normalizado suportando multi-estado,
**so that** tenhamos um banco de dados estruturado para armazenar dados de municípios, conselhos, reuniões e relatórios.

---

## Acceptance Criteria

1. Schema Prisma criado com model `Estado` suportando multi-estado (expansão nacional)
2. Model `Municipio` com campos: codigo_ibge, nome, estado_id, populacao, indice_antifome, status, coordenadas
3. Model `Conselho` com campos: municipio_id, nome, status (ativo/inativo/suspenso)
4. Model `Membro` com campos: conselho_id, nome, cargo (presidente/vice/membro), contato, email
5. Model `Reuniao` com campos: conselho_id, data, tipo (ordinaria/extraordinaria), pauta, ata_url
6. Model `RelatorioFome` com campos: municipio_id, mes_ano, nivel_gravidade, dados_json
7. Model `Selo` com campos: municipio_id, tipo (bronze/prata/ouro/platina), conquistado_em
8. RelaçõesMany-to-Many e One-to-Many configuradas corretamente
9. Índices criados para campos frequentemente consultados
10. Migration executada com sucesso no PostgreSQL
11. Prisma Client gerado sem erros

## Dev Notes

### Contexto do Projeto

Schema do banco de dados que suporta a aplicação Antifome RS. O schema é normalizado e preparado para expansão multi-estado (atualmente focado no RS, mas estruturado para incluir outros estados brasileiros).

### Models e Relações

```
Estado (1) ──→ (∞) Municipio
Municipio (1) ──→ (∞) Conselho
Municipio (1) ──→ (∞) RelatorioFome
Municipio (1) ──→ (∞) Selo
Conselho (1) ──→ (∞) Membro
Conselho (1) ──→ (∞) Reuniao
Municipio (0..1) ──→ (∞) Usuario
```

### Distribuição de Status dos Municípios (para Seed Data)

O schema suporta a distribuição realista do RS:
- **Ativo**: 71% (~353 municípios)
- **Inativo**: 17% (~84 municípios)
- **Atrasado**: 12% (~60 municípios)

### Campos Calculados

- **Índice Antifome**: Calculado via fórmula `((Reuniões / 12) × 0.4 + (Relatórios / 5) × 0.6) × 10`
- O campo `indice_antifome` no schema armazena o valor pré-calculado

### Enums do Schema

```prisma
enum StatusMunicipio {
  ATIVO
  INATIVO
  ATRASADO
}

enum Cargo {
  PRESIDENTE
  VICE
  MEMBRO
}

enum TipoReuniao {
  ORDINARIA
  EXTRAORDINARIA
}

enum NivelGravidade {
  BAIXO
  MODERADO
  ALTO
  CRITICO
}

enum TipoSelo {
  BRONZE
  PRATA
  OURO
  PLATINA
}

enum Role {
  ADMIN
  GESTOR_ESTADUAL
  CONSELHEIRO_MUNICIPAL
}
```

### Índices Críticos

| Model | Índice | Justificativa |
|-------|--------|---------------|
| Municipio | codigo_ibge (unique) | Lookup por código IBGE |
| Municipio | estado_id + status | Filtros do dashboard |
| RelatorioFome | municipio_id + mes_ano | Histórico por município |
| Reuniao | conselho_id + data | Reuniões recentes |
| Membro | conselho_id + cargo | Validação presidente único |
