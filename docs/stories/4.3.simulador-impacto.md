1. Página `/simulador` com simulador interativo
2. Slider de eficiência de 50% a 100%
3. Valor padrão: 70% (eficiência atual)
4. Cálculo em tempo real:
   - Famílias Totais RS: 1.294.950
   - Famílias Atendidas = Total × Eficiência
   - Famílias Adicionais = Atendidas(atual) → Atendidas(nova)
5. Exibição de resultado formatado:
   - "Se a eficiência aumentar de 70% para 85%, são **194.243 famílias a mais** atendidas sem gastar um real extra."
6. Animação de transição nos números
7. Gráfico visual: barras comparando cenários
8. Botão de compartilhar resultado
9. Design visualmente impactante para apresentação

## Dev Notes

### Contexto do Projeto

Ferramenta de demonstração para o pitch do hackathon. Mostra o impacto real do sistema em famílias atendidas.

### Fórmula do Simulador

```typescript
const TOTAL_FAMILIAS = 1294950;
const EFICIENCIA_ATUAL = 0.70; // 70%

function calcularImpacto(novaEficiencia: number) {
  const atendidasAtual = TOTAL_FAMILIAS * EFICIENCIA_ATUAL;
  const atendidasNova = TOTAL_FAMILIAS * novaEficiencia;
  const adicionais = atendidasNova - atendidasAtual;

  return {
    atendidas: Math.round(atendidasNova),
    adicionais: Math.round(adicionais),
    percentual: Math.round((novaEficiencia - EFICIENCIA_ATUAL) * 100)
  };
}
```

### Exemplo de Output

```
"Se a eficiência de alocação aumentar de 70% para 85%,
são 194.243 famílias a mais atendidas sem gastar um real extra."

Cálculo: 1.294.950 × (0.85 - 0.70) = 194.242,5
```
