## Story

**As a** gestor estadual,
**I want** um ranking de municípios ordenável com busca e filtros,
**so that** eu possa comparar municípios e identificar os que precisam de atenção.

---

## Acceptance Criteria

1. Página `/ranking` com tabela de municípios
2. Tabela mostra: posição, nome, status, índice antifome, população, selo
3. Ordenação por qualquer coluna (clicável)
4. Ordenação padrão: índice antifome (decrescente)
5. Busca por nome do município
6. Filtro por status (Ativo, Inativo, Atrasado, Todos)
7. Filtro por região (se aplicável)
8. Paginação: 20 itens por página
9. Click no município navega para `/municipios/{id}`
10. Total de municípios exibido (ex: "Mostrando 1-20 de 497")
11. Loading skeleton enquanto carrega
12. API backend com paginação e filtros

## Dev Notes

### Contexto do Projeto

Página de ranking permite comparação entre municípios, ordenando por diferentes critérios. Essencial para gestores identificarem prioridades.

### API Response

```json
{
  "data": [
    {
      "id": 1,
      "codigo_ibge": "4314902",
      "nome": "Porto Alegre",
      "status": "ATIVO",
      "indice_antifome": 8.5,
      "populacao": 1488000,
      "selo_atual": "OURO"
    }
  ],
  "total": 497,
  "page": 1,
  "totalPages": 25,
  "hasNext": true,
  "hasPrev": false
}
```

### Colunas da Tabela

| # | Município | Status | Índice | População | Selo |
|---|-----------|--------|--------|-----------|------|
| 1 | Porto Alegre | ATIVO | 8.5 | 1.488.000 | OURO |
| 2 | Caxias do Sul | ATIVO | 7.9 | 517.000 | PRATA |

### Filtros Disponíveis

- **Status**: Todos, ATIVO, INATIVO, ATRASADO
- **Região**: Metropolitana, Serra, Fronteira, Sul, Noroeste, Nordeste, Centro-Oeste, Pampa (opcional)
