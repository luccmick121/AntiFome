## Story

**As a** conselheiro presidente,
**I want** um CRUD de membros do conselho com validações,
**so that** eu possa cadastrar, atualizar e remover membros mantendo a integridade do conselho.

---

## Acceptance Criteria

1. Página `/conselho/membros` com lista de membros do conselho
2. Formulário de cadastro de membro (nome, cargo, email, telefone)
3. Validações:
   - Nome obrigatório (mínimo 3 caracteres)
   - Email válido e único dentro do conselho
   - Cargo: PRESIDENTE, VICE, MEMBRO
   - Máximo 1 presidente por conselho
   - Mínimo 1 presidente no conselho
4. Edição de membro existente
5. Remoção de membro com confirmação
6. Preservação: não permitir remover último presidente
7. Lista ordenada por cargo (presidente primeiro)
8. Badge visual indicando cargo de cada membro
9. API backend com CRUD completo
10. Feedback visual de sucesso/erro em cada operação

## Dev Notes

### Contexto do Projeto

CRUD de membros permite ao presidente do conselho gerenciar a equipe. Validações garantem a integridade (sempre 1 presidente).

### DTO de Membro

```typescript
interface CreateMembroDto {
  nome: string;        // min 3 chars
  cargo: 'PRESIDENTE' | 'VICE' | 'MEMBRO';
  email: string;       // valid email, unique in conselho
  telefone: string;    // optional, format: (XX) XXXXX-XXXX
}
```

### Validações de Negócio

```
1. Máximo 1 presidente por conselho
   → Se tentar cadastrar 2º presidente: erro 400
   → Solução: mudar cargo do atual para MEMBRO primeiro

2. Não remover último presidente
   → Se só restar 1 presidente: bloquear exclusão
   → Mensagem: "Não é possível remover o único presidente"

3. Email único
   → Verificar se email já existe no conselho
   → Ignorar se for o próprio membro (update)
```

### Ordenação da Lista

```
1. PRESIDENTE
2. VICE
3. MEMBRO (alfabético)
```
