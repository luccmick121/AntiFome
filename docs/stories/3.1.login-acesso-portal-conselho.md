## Story

**As a** conselheiro municipal,
**I want** um login específico para o portal do conselho com verificação de papel,
**so that** eu possa acessar apenas as funcionalidades do meu conselho municipal.

---

## Acceptance Criteria

1. Rota `/conselho/login` com formulário de acesso
2. Autenticação reutiliza JWT do sistema principal
3. Verificação de papel: apenas usuários com role CONSELHEIRO_MUNICIPAL acessam
4. Verificação de vínculo: usuário deve estar vinculado a um conselho ativo
5. Após login, redireciona para `/conselho` (home do portal)
6. Header do portal mostra: nome do município, status atual, Índice Antifome
7. Barra de progresso para o próximo selo (ex: "Faltam 2 reuniões para o selo Bronze")
8. Se conselho suspenso, mostra mensagem de aviso e bloqueia funcionalidades
9. Layout do portal diferente do dashboard (design exclusivo para conselheiros)
10. Menu de navegação do portal: Home, Membros, Reuniões, Documentos

## Dev Notes

### Contexto do Projeto

Portal exclusivo para conselheiros municipais gerenciarem seu conselho. Requer autenticação específica com verificação de vínculo com conselho ativo.

### Fluxo de Acesso

```
1. Usuário acessa /conselho
2. Middleware verifica JWT
3. Verifica role = CONSELHEIRO_MUNICIPAL
4. Busca conselho vinculado ao usuário
5. Se conselho ativo → /conselho
6. Se conselho suspenso → modal de aviso + /conselho (restrito)
7. Se sem conselho → /login + erro
```

### Dados do Header

```typescript
interface ConselhoHeaderData {
  municipio: {
    nome: string;
    codigo_ibge: string;
  };
  conselho: {
    status: 'ATIVO' | 'SUSPENSO';
    indiceAntifome: number;
  };
  selo: {
    atual: TipoSelo | null;
    proximo: TipoSelo | null;
    progresso: number; // 0-100
    reunioesFaltando: number;
  };
}
```

### Barra de Progresso para Selos

| Selo | Reuniões Necessárias | Relatórios Necessários |
|------|---------------------|------------------------|
| BRONZE | 6 reuniões/semestre | 3 relatórios |
| PRATA | 10 reuniões/ano | 6 relatórios |
| OURO | 12 reuniões/ano (100%) | 10 relatórios |
| PLATINA | 12 reuniões + extras | 12 relatórios |
