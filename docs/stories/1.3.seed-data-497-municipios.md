## Dev Notes

### Contexto do Projeto

Este story popula o banco de dados com dados realistas do Rio Grande do Sul para permitir testes e desenvolvimento das funcionalidades de dashboard, ranking e portal do conselho.

### Dados dos Municípios

O arquivo `prisma/data/municipios-rs.ts` deve conter os 497 municípios com:
- Código IBGE de 7 dígitos
- Nome oficial do município
- População estimada (IBGE 2024)
- Coordenadas geográficas (centroide do município)

### Distribuição de Status

```
Total: 497 municípios
├── ATIVO (71%): 353 municípios
│   └── Conselho ativo, reuniões regulares, índice alto
├── INATIVO (17%): 84 municípios
│   └── Sem conselho ou conselho inativo, índice baixo
└── ATRASADO (12%): 60 municípios
    └── Conselho existe mas irregular, índice médio
```

### Fórmula do Índice Antifome

```
Índice = ((Reuniões / 12) × 0.4 + (Relatórios / 5) × 0.6) × 10

Onde:
- 12 = máximo de reuniões trimestrais (1 por mês × 3)
- 5 = máximo de relatórios mensais
- Score final: 0-10
```
