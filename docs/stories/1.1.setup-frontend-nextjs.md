## Dev Notes

### Contexto do Projeto

Este é o primeiro story do Epic 01 (Fundação e Infraestrutura). O objetivo é estabelecer a base técnica do frontend para a aplicação Antifome RS, um sistema de gestão da segurança alimentar no Rio Grande do Sul.

### Stack Tecnológica

- **Framework**: Next.js 14 com App Router (Server Components por padrão)
- **Styling**: Tailwind CSS + shadcn/ui
- **Language**: TypeScript com strict mode
- **Estado**: React Context + Zustand (definido em stories posteriores)

### Design System (do PRD)

| Elemento | Valor |
|----------|-------|
| Primária | `#1A2F23` (Verde Petróleo) |
| Urgência | `#B71C1C` (Vermelho Sangue) |
| Sucesso | `#2E7D32` (Verde Folha) |
| Aviso | `#FF8F00` (Âmbar) |
| Erro | `#D32F2F` (Vermelho Vivo) |
| Fundo | `#F5F5F5` (Cinza Gelo) |
| Texto | `#212121` (Grafite) |
| Tipografia | Roboto / Public Sans |

### Dependências

- `next@14` - Framework
- `react@18` + `react-dom@18`
