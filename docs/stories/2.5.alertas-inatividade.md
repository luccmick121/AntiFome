## Story

**As a** gestor estadual,
**I want** um sistema de alertas de inatividade com lista de municípios problemáticos e botão "Quebrar Silêncio",
**so that** eu possa identificar e contatar municípios que não estão cumprindo suas obrigações.

---

## Acceptance Criteria

1. Página `/alertas` com dashboard de alertas
2. Contador de alertas por categoria:
   - Municípios sem reunião > 90 dias
   - Municípios sem relatório > 30 dias
   - Conselhos suspensos
3. Lista de municípios inativos/atrasados
4. Cada item mostra: nome, município, dias desde última atividade, contato
5. Botão "Quebrar Silêncio" por município
6. Ação "Quebrar Silêncio": registra intenção de contato e notifica gestor
7. Filtros: por tipo de alerta, por região
8. Ordenação: por dias de inatividade (maior primeiro)
9. API backend para alertas com lógica de negocio
10. Dashboard com resumo visual (cards com contadores)

## Dev Notes

### Contexto do Projeto

Sistema de alertas identifica municípios que não estão cumprindo obrigações (reuniões, relatórios) e facilita a intervenção do gestor estadual.

### Tipos de Alerta

| Tipo | Condição | Severidade |
|------|----------|------------|
| Sem Reunião | > 90 dias sem reunião | Alta |
| Sem Relatório | > 30 dias sem relatório | Média |
| Conselho Suspenso | Status SUSPENSO | Crítica |

### API Response

```json
{
  "alertas": [
    {
      "id": 1,
      "tipo": "SEM_REUNIAO",
      "municipio_id": 4300105,
      "municipio_nome": "Aceguá",
      "dias_inatividade": 145,
      "ultimo_evento": "2025-10-20",
      "contato": "conselho@acegua.rs.gov.br",
      "severidade": "ALTA"
    }
  ],
  "total": 42,
  "resumo": {
    "sem_reuniao": 28,
    "sem_relatorio": 12,
    "conselho_suspenso": 2
  }
}
```

### Ação "Quebrar Silêncio"

1. Gestor clica no botão
2. Confirmação: "Deseja registrar intenção de contato?"
3. Backend registra: timestamp, gestor, município
4. Log para auditoria
5. Notificação visual de sucesso
