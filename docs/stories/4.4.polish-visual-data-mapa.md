## Story

**As a** usuário do sistema,
**I want** polish visual final com design system consistente, loading states, favicon e transições suaves,
**so that** a aplicação tenha aparência profissional e pronta para apresentação.

---

## Acceptance Criteria

1. Design system consistente em todas as páginas:
   - Paleta: #1A2F23 (primária), #B71C1C (urgência), #2E7D32 (sucesso)
   - Tipografia: Roboto / Public Sans
   - Botões: cantos vivos (máx 2px raio)
   - Background: #F5F5F5 (Cinza Gelo)
2. Loading states (skeleton) em todas as páginas que fazem fetch
3. Favicon "Antifome RS" em todas as páginas
4. Título da aba: "Antifome RS - [Página]"
5. Transições suaves entre telas (page transitions)
6. Mapa com geometria real dos 497 polígonos do IBGE
7. Banner de alerta funcional e visível (se houver municípios críticos)
8. Animações sutis em hover, click, loading
9. Scroll suave em navegação interna
10. Mensagens de erro elegantes (não console errors)

## Dev Notes

### Contexto do Projeto

Story final do projeto. Aplica polish visual para tornar a aplicação profissional e pronta para apresentação no hackathon.

### Design System

```css
:root {
  --primary: #1A2F23;
  --danger: #B71C1C;
  --success: #2E7D32;
  --warning: #FF8F00;
  --error: #D32F2F;
  --background: #F5F5F5;
  --text: #212121;
  --font-sans: 'Roboto', 'Public Sans', sans-serif;
}
```

### Favicon

- `favicon.ico`: 16x16, 32x32, 48x48
- `icon-192.png`: 192x192 (PWA)
- `icon-512.png`: 512x512 (PWA)
- Tema: logo "AF" estilizado em verde petróleo

### Loading Skeleton Padrão

```tsx
<Skeleton className="h-4 w-[250px]" />  // Texto
<Skeleton className="h-8 w-[200px]" />  // Título
<Skeleton className="h-[200px] w-full" /> // Card grande
```

### Page Transition

```css
.page-transition {
  animation: fadeIn 0.3s ease-in-out;
}

@keyframes fadeIn {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}
```
