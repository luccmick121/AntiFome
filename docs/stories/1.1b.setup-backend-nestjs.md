## Story

**As a** desenvolvedor,
**I want** configurar o projeto backend com NestJS, incluindo Swagger e módulos principais,
**so that** tenhamos uma API REST robusta e documentada para alimentar o frontend.

---

## Acceptance Criteria

1. Projeto NestJS criado com CLI e estrutura modular
2. Swagger configurado e acessível em `/api/docs`
3. Módulos principais criados: Auth, Municipes, Conselhos, Dashboard
4. CORS configurado para o frontend (`localhost:3000`)
5. Configuração de TypeORM/Prisma para PostgreSQL
6. Pipes e interceptors globais de validação
7. Health check endpoint em `/api/health`
8. Scripts npm funcionais: `start:dev`, `build`, `start:prod`
9. Logger configurado com niveis apropriados

## Dev Notes

### Contexto do Projeto

Este story é executado em paralelo com a Story 1.1 (Setup Frontend). O backend NestJS fornecerá a API REST que o frontend consumirá.

### Stack Tecnológica

- **Framework**: NestJS 10 com TypeScript
- **API Docs**: Swagger/OpenAPI
- **Database**: PostgreSQL via Prisma (schema definido na Story 1.2)
- **Auth**: JWT com Passport

### Estrutura de Módulos Prevista

### Endpoints Iniciais

| Método | Endpoint | Descrição |
|--------|----------|-----------|
| GET | `/api/health` | Health check |
| GET | `/api/docs` | Swagger UI |
| GET | `/api/docs-json` | OpenAPI JSON |

### Dependências Principais

- `@nestjs/core`, `@nestjs/common`, `@nestjs/platform-express`
- `@nestjs/swagger`, `swagger-ui-express`
- `@nestjs/passport`, `@nestjs/jwt`, `passport`
- `@prisma/client` (instalado na Story 1.2)
- `class-validator`, `class-transformer`
- `helmet`, `compression` (segurança e performance)

### Portas

- Backend: `localhost:3001`
- Swagger: `localhost:3001/api/docs`
