## Story

**As a** gestor estadual,
**I want** um mapa interativo do RS com polígonos coloridos por status e camadas toggles,
**so that** eu possa visualizar a situação dos municípios de forma geográfica e alternar entre diferentes visões.

---

## Acceptance Criteria

1. Mapa Leaflet renderizado na página `/mapa`
2. 497 polígonos renderizados como choropleth colorido por status
3. Clique no município navega para `/municipios/{id}`
4. Tooltip ao hover mostra: nome, status, índice antifome
5. 4 camadas toggles funcionais:
   - Base (polígonos por status)
   - IAG (heatmap de gravidade)
   - Cozinhas Solidárias (pins)
   - PPSAN (pins)
6. Controles de zoom funcionais (+ / - / reset)
7. Legenda do mapa com cores e significado
8. Mapa renderiza em < 3 segundos
9. Responsivo: ajusta tamanho em mobile
10. Loading state enquanto carrega GeoJSON

## Dev Notes

### Contexto do Projeto

Componente central do dashboard estadual. O mapa choropleth permite visão geográfica rápida da situação dos municípios, com camadas adicionais para análise multidimensional.

### Configuração Leaflet

```typescript
const MAP_CENTER: LatLngTuple = [-30.0346, -51.2177]; // Centro do RS
const DEFAULT_ZOOM = 7;
const MIN_ZOOM = 6;
const MAX_ZOOM = 12;
```

### Camadas

| Camada | Tipo | Fonte | Visibilidade |
|--------|------|-------|--------------|
| Base | Choropleth | API `/api/mapa/geojson` | Sempre visível |
| IAG | Heatmap | `relatorios_fome` | Toggle |
| Cozinhas | Pins | Dados simulados | Toggle |
| PPSAN | Pins | Dados simulados | Toggle |

### Cores do Choropleth

| Status | Cor | Opacidade |
|--------|-----|-----------|
| ATIVO | `#2E7D32` | 0.8 |
| ATRASADO | `#FF8F00` | 0.8 |
| INATIVO | `#D32F2F` | 0.8 |

### Dependências

- `leaflet` - Mapa base
- `react-leaflet` - Wrapper React para Leaflet
- `@types/leaflet` - Tipos TypeScript
