## Story

**As a** gestor municipal ou conselheiro,
**I want** um dashboard de status mostrando SISAN, CAISAN, Plano Municipal SAN e barra de progresso para selos,
**so that** eu possa acompanhar o cumprimento das obrigações e planejar ações para alcançar selos melhores.

---

## Acceptance Criteria

1. Dashboard mostra status de cada obrigação:
   - SISAN: adherence status (Adesão/Implementação/Consolidação)
   - CAISAN: composição e funcionamento
   - Plano Municipal SAN: vigência e execução
2. Barra de progresso visual para cada selo (Bronze, Prata, Ouro, Platina)
3. Indicadores de reuniões: realizadas vs necessárias no período
4. Indicadores de relatórios: enviados vs necessários
5. Calendário ou timeline de próximas reuniões obrigatórias
6. Comparativo: desempenho atual vs requisitos do próximo selo
7. Recomendações: "Para alcançar o selo Prata, faltam X reuniões e Y relatórios"
8. Dados vindos da API backend agregados
9. Design visual claro com cores semânticas (verde=ok, amarelo=atenção, vermelho=crítico)

## Dev Notes

### Contexto do Projeto

Dashboard de progresso ajuda conselheiros e gestores a entender onde estão e o que falta para melhorar o selo.

### Requisitos dos Selos

| Selo | Reuniões/Ano | Relatórios/Ano | Requisitos Extras |
|------|-------------|----------------|-------------------|
| BRONZE | 6 | 3 | Conselho registrado |
| PRATA | 10 | 6 | + Membro mínimo 5 |
| OURO | 12 | 10 | + Atas todas as reuniões |
| PLATINA | 12 | 12 | + Plano SAN aprovado |

### Status SISAN

```typescript
type AdesaoSISAN =
  | 'NAO_ADESAO'     // Não aderiu
  | 'ADESAO'         // Aderiu, implementando
  | 'IMPLEMENTACAO'  // Implementando
  | 'CONSOLIDACAO';  // Consolidado
```
