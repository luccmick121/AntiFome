## Story

**As a** gestor estadual,
**I want** um layout com sidebar colapsável e barra de KPIs no topo,
**so that** eu possa navegar entre as funcionalidades e ter visão rápida dos indicadores principais.

---

## Acceptance Criteria

1. Layout com sidebar colapsável implementado
2. Sidebar contém links de navegação: Dashboard, Mapa, Ranking, Alertas, Gestão CONSEA
3. Sidebar exibe logo/nome "Antifome RS" no topo
4. Barra de KPIs no topo com 3 cards: Total Municípios, Municípios Ativos, Índice Médio
5. KPIs conectados à API e atualizados em tempo real
6. Layout responsivo: sidebar colapsa em mobile
7. Header exibe nome do usuário logado e botão de logout
8. Área de conteúdo principal com scroll independente
9. Animações suaves na colapsação da sidebar
10. Estado da sidebar persistido no localStorage

## Dev Notes

### Contexto do Projeto

Layout base que será usado por todas as páginas do dashboard. Estabelece a estrutura visual da aplicação com sidebar de navegação e KPIs de monitoramento.

### Estrutura do Layout

```
┌─────────────────────────────────────────────────────┐
│ Header (nome usuário, logout)                       │
├──────────┬──────────────────────────────────────────┤
│          │ KPI Bar (3 cards)                        │
│ Sidebar  ├──────────────────────────────────────────┤
│ (links)  │                                          │
│          │ Main Content (page content)              │
│          │                                          │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

### KPI Cards (Especificações)

| KPI | Título | Formato | Cor |
|-----|--------|---------|-----|
| Total | Total Municípios | `497` | Verde Petróleo |
| Ativos | Municípios Ativos | `353 (71%)` | Verde Folha |
| Índice | Índice Antifome Médio | `6.8` | Âmbar |

### Componentes shadcn/ui a Usar

- `Card`, `CardContent`, `CardHeader`, `CardTitle` - KPI cards
- `Button` - Ações do header
- `Skeleton` - Loading states
- `Tooltip` - Info nos KPIs
- `Avatar` - Foto do usuário

### Hook de API

```typescript
// src/hooks/use-dashboard-stats.ts
export function useDashboardStats() {
  // GET /api/dashboard/stats
  // Retorna: { total, ativos, inativos, atrasados, indiceMedio }
}
```

### Animações

- Sidebar: `transition-all duration-300 ease-in-out`
- KPI cards: `transition-transform hover:scale-105`
- Loading skeletons: `animate-pulse`
