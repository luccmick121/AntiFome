# Design System do Antifome RS

Esta área documenta a linguagem visual do produto, a base de componentes e os princípios usados para a interface estadual, o portal do conselho e os materiais de apresentação.

## Objetivo

Garantir que o Antifome tenha uma identidade:

- institucional, sem parecer burocrática;
- minimalista, sem parecer genérica;
- operacional, sem perder sofisticação;
- consistente entre login, dashboard, mapas e portal municipal.

## O Que Está Coberto

- direção visual do produto;
- componentes reutilizáveis;
- tokens de cor, tipografia e spacing;
- padrões de estados e hierarquia;
- base de mapas e leitura territorial;
- governança visual para continuidade do projeto.

## Navegação Recomendada

- componentes: `/design-system/components`
- foundations e tokens: `/design-system/tokens`

## Relação com o Produto

O design system não é um material paralelo. Ele existe para sustentar:

- o login institucional;
- a dashboard estadual;
- o portal do conselho;
- o deck do hackathon;
- a evolução futura do produto.

## Resultado Esperado

Qualquer nova tela do projeto deve conseguir nascer a partir desta base sem quebrar:

- clareza;
- consistência;
- legibilidade;
- tom institucional;
- capacidade de apresentação para banca e stakeholders.
